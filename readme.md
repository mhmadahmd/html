> **Maintained fork** (by [@mhmadahmd](https://github.com/mhmadahmd)) of the abandoned
> [laravelcollective/html](https://github.com/LaravelCollective/html), based on the final upstream release v6.4.1.
> This fork widens framework support to **Laravel 6 through 12** and makes the
> `ConvertEmptyStringsToNull` detection compatible with the Laravel 11 kernel changes.
> Install via a VCS repository entry pointing at this repository.
